Проект: Музыкальный плеер

На сегодняшний день существует много платформ для прослушивания музыки: ВК Музыка, Яндекс Музыка и т.д. Но есть один нюанс: та музыка, которая есть на одной платформе, не всегда присутствует на другой. В результате имеем несколько платформ для прослушивания музыки, которые содержат как общие треки, так и индивидуальные. Задумкой моего проекта было сделать платформу, которая постарается объединить все треки в одном приложении для прослушивания.

Описание работы программы:
Первоначально мы видим базовую страницу для входа/регистрации пользователя. Без регистрации пользователь не имеет доступа ни к чему. После регистрации на введённую пользователем почту отправляется верификационный 6-значный код, который действителен 5 минут.
После входа пользователь попадает в профиль, где видит основную информацию о себе: имя, почта, роль (обычный пользователь или админ), а также информацию о загрузках его треков.
При нажатии на кнопку «Поиск музыки» пользователь попадает на страницу с формой для ввода названия песни. При выборе песни автоматически строится очередь из всех треков для дальнейшего прослушивания. Имеется также базовый набор кнопок: перемешать очередь, предыдущий трек, следующий трек, повтор данного трека бесконечное количество раз и вывод очереди воспроизведения. Очередь кликабельна — при нажатии на любой трек пользователь переходит на него, и очередь продолжается с данного трека.
У пользователя есть возможность добавления собственного трека: он вводит название трека, автора трека и загружает сам файл (поддерживаемые форматы: .mp3, .wav, .ogg, .flac). После нажатия на кнопку «Save» песня отправляется на модерацию админу. После проверки админ либо одобряет добавление, либо отклоняет — оба случая сопровождаются ответным письмом на почту пользователя с результатом модерации.
Также ддоступна опция "Мои плейлисты", где пользователь может создавать свои цепочки песен на любой вкус.

В дальнейшем планируется:
- Добавить модели для артистов и связать треки с их авторами
- Изменить логику создания очереди воспроизведения
- Добавить валидацию по жанрам и настроению треков

Инструменты разработки:
- Язык программирования: Python 3
- Фреймворк: Flask
- База данных: SQLite
- ORM: SQLAlchemy
- Миграции БД: Flask-Migrate (Alembic)
- Аутентификация: Flask-Login
- Формы: Flask-WTF (WTForms)
- Отправка писем: smtplib (SMTP через Mail.ru)
- Хэширование паролей: Werkzeug Security
- Фронтенд: HTML5, Jinja2, JavaScript
- Аудиоплеер: HTML5 Audio API
- Контроль версий: Git, GitHub

В файле requirements.txt представлен полный пакет используемый зависимостей.
